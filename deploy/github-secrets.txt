GitHub → repo → Settings → Secrets and variables → Actions → New repository secret

Wymagane (deploy):
  VPS_HOST          — IP lub domena VPS
  VPS_USER          — użytkownik SSH (np. deploy)
  VPS_SSH_KEY       — prywatny klucz SSH (cały plik, -----BEGIN...)
  VPS_DEPLOY_PATH   — katalog na VPS, np. /opt/sofia-art

Wymagane (build React w obrazie):
  REACT_APP_SUPABASE_URL
  REACT_APP_SUPABASE_ANON_KEY
  REACT_APP_WEB3FORMS_ACCESS_KEY

Opcjonalne:
  VPS_SSH_PORT      — domyślnie 22
  GHCR_TOKEN        — Personal Access Token (read:packages), jeśli obraz w GHCR jest prywatny

Po pierwszym pushu na master: Packages → sofia-art-site → Package settings → Change visibility → Public
(albo ustaw GHCR_TOKEN na VPS i w sekretach GitHub)
